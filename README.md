# TRIPTONE — Travel Search Frontend

Responsive, Skyscanner-inspired flight comparison frontend with original TRIPTONE branding, built with HTML, CSS and vanilla JavaScript.

## Features
- Round-trip and one-way search, airport swap, date validation, traveller selection
- Sample flight results with airline, departure/arrival, stops, duration and INR fares
- Sorting by recommended, lowest price, shortest journey and departure time
- Filters for stops, max price, departure time, airline and direct flights
- Responsive mobile/desktop layout

## Run locally
Open `index.html` in a browser or run `python3 -m http.server 8000` and visit http://localhost:8000.

## Publish with GitHub Pages
Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Important
Flight results and prices are sample data only. Live inventory, booking and checkout are not connected.
